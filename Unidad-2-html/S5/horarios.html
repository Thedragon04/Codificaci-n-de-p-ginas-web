Como entregar una practica: con lista ordenada

  1. Traer los cambios con git pull
  2. Crear la rama de la practica con git switch -c "nombre_rama"
  3. Trabajar y hacer commits atomicos
  4. Subir la rama con git push
  5. Abrir un pull request en github
  6. Revisar y fusionar el pull request
  7. Volver a la rama principal (main)
  8. Eliminar la rama de la practica con git branch -d "nombre de la rama"
